## 怎么回滚

```powershell
Copy-Item 存档\v1_纯表级大字版\* . -Force
```

1. 改 `build_svg.py` → `python build_svg.py` → `python render.py` → `python build_drawio.py`
2. 新建 `存档\vN_<一句话标签>\`，把 4 个成品 + README 拷进去
3. 在上表加一行
