### 重建数据

```bash
# 重新生成 SQL 与前端种子（会覆盖两处数据段，DDL / 视图 / 触发器 / 过程不变）
python tools/gen_demo_data.py

# 导入数据库
mysql -u root -p < sql/risk_alert_示例库.sql
```

> 生成器内置 40 余项断言（时间轴、外键、唯一键、CHECK、生成列、评分可复算、线索 1:1、
> 批次计数、评估标签），任何一项不通过都不会落盘。

### 前端刷新

模拟库把数据存在浏览器 localStorage 中。换成本版数据后，登录 → 右上角用户菜单 →
「重置演示数据」即可加载新数据（或清除站点数据）。

## 风险地图（前端新增功能）

前端新增 **B3 风险地图** 页面（`/risk-map`，见 frontend/README.md）：

- **按地区以红色深浅展示风险等级**：颜色越深风险越高，区域取自数据库区域表 `area_info`；
- **可拖动时间轴**：拖动滑块（或点「播放」自动轮播）切换不同观察夜，查看各区域风险随时间的变化；
- **地点与数据库一致**：为此给 `area_info` 新增了经纬度字段 `lng` / `lat`（`DECIMAL(10,6)`，虚构坐标，仅用于教学演示，不对应真实地理位置），并加 `ck_area_coord` 坐标范围约束。三处已同步更新：

| 文件 | 变更 |
|---|---|
| `sql/risk_alert_示例库.sql` | `area_info` 建表 DDL 新增 `lng`/`lat` + `ck_area_coord` CHECK；数据段写入 12 个示例坐标 |
| `tools/gen_demo_data.py` | `AREAS` 常量新增坐标，重新生成即可同步 SQL 与前端种子 |
| `frontend/src/api/mock/seed.js` | 区域种子同步带上 `lng`/`lat` |

> 结构变化：CHECK 由 64 → **65** 个；表数（26）、外键（45）不变。相关说明见 `explain.md`、`数据库设计思路方案.md`、`前端交接文档.md`（新增接口 #25 `/api/risk-map`）。
